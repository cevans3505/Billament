# Phase 2, Plan 02: Release checksums, and the QuestPDF license condition in the docs

## Phase Goal

ROADMAP Goal line (verbatim): "The concerns with the best benefit for the cost (triage score 2.0 and above) are fixed in
score order, so releases can be checked, invoices already sent are guarded by a test, and paths, file names and update
checks are handled safely."

The Goal line is not a user story; the stories below restate the parts this plan delivers without adding scope. Run
`/gsd-mvp-phase 2` to replace them with canonical stories if wanted.

**As someone** downloading a PrintInvoicer release, **I want to** compare the zip's SHA-256 with the one in the
release notes, **so that** I know my download is complete and is the file the release describes.
**As someone** deciding whether to use PrintInvoicer for a business, **I want** the README to state the QuestPDF
license condition, **so that** I know when I would need a paid QuestPDF license.

This plan delivers FIX-01 (C11, score 3.00, first in score order) and FIX-07 (C22, 2.00). It shares no file with plan
02-01, so both run in Wave 1. Plans 02-03 and 02-04 edit AUDITING.md after it.

<objective>
Make every tagged release publish `PrintInvoicer-<version>.zip.sha256` next to the zip with the hash in the draft
notes, tell the maintainer to keep that line, tell users how to check it, and state the QuestPDF Community license
revenue condition in README and AUDITING.md.

Purpose: releases can be checked, and the license condition is not a surprise.
Output: edited `.github/workflows/release.yml`, `README.md`, `AUDITING.md`, `CLAUDE.md`.
</objective>
