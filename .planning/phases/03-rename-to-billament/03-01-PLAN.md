# Phase 3, Plan 01 [cloud]: Rename the code, scripts, workflows and docs to Billament

## Phase Goal

ROADMAP Goal line (verbatim): "PrintInvoicer becomes Billament everywhere (code, app, PDFs, scripts, docs, data folders
and the GitHub repository), existing users keep every job and finalized invoice through a one-time safe move of their
data, and the result ships as 4.0.0, so later phases are built under the new name from the start."

The Goal line is not written as a user story. The stories below restate its outcomes without adding scope. Run
`/gsd-mvp-phase 3` to replace them with canonical stories if wanted.

**As a** Billament user, **I want to** see Billament in every window, dialog, update bar and file name, **so that**
the app I run matches the name on its release page.
**As a** user upgrading from 3.7.0, **I want to** start 4.0.0 and find every job and finalized invoice exactly as before,
**so that** the rename costs me nothing.
**As the** maintainer, **I want to** build, test, publish and release under the new name with one consistent set of
scripts and docs, **so that** later phases are written under Billament from the start.

This plan delivers the mechanical part of the rename: every file, folder, namespace, string, script, workflow and doc
moves to the new name, and the version becomes 4.0.0. It writes no old-name string on purpose: after it, a search for the
old name outside the planning folder finds nothing, so every old-name string that later plans add (the data move, old
backup names, the old-install cleanup, the rename notes) is deliberate.

**Path names in this plan:** the `git mv` steps use the old names (they are the sources); every other path in this
plan, including `files_modified` above, uses the new `Billament.*` names that exist after Task 1.

<objective>
Where it runs: [cloud] (Linux: renames, Core and test build, docs, workflow and script text).

Rename the whole code base with `git mv` and one scripted text replacement, gated by a Linux build of the solution and
the 485 unit tests; then rename the scripts, workflows and docs the same way, set version 4.0.0 and the read-me heading
`Billament 4.0`, and update the three product-name lines of PROJECT.md by hand.

Execution route: scripted, with no file-by-file reading. The 99 files in `files_modified` are changed by `git mv` and
two scripted replacements, not opened one by one; the binding rules and the token count are in "Context budget and
execution route" below.

Purpose: NAME-01 and the code parts of NAME-02, NAME-05, NAME-06, NAME-07 and NAME-08, with a clean zero-hit baseline
for the deliberate old-name strings written by plans 03-02 to 03-04.
Output: `Billament.sln`, four renamed projects, all strings and docs under the new name, `<Version>4.0.0</Version>`.
</objective>
